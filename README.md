# Sidepocket Releases

Sidepocket for macOS의 공식 배포 저장소입니다.

이 저장소에는 설치 파일, 체크섬, 업데이트 확인용 버전 정보만 포함됩니다. Sidepocket의 소스 코드는 포함되지 않으며 오픈소스 저장소가 아닙니다.

## 설치

1. [최신 Release](https://github.com/taekilKim/sidepocket-releases/releases/latest)에서 DMG를 다운로드합니다.
2. Sidepocket을 Applications 폴더로 옮깁니다.
3. 현재 배포본은 Developer ID로 서명되지 않았으므로 최초 실행 시 Finder에서 앱을 Control-클릭하고 `열기`를 선택해야 할 수 있습니다.
